## Appeal Evidence Bridge



A browser extension built by a veteran to fix a navigation failure on VA.gov.



## The Problem



When a veteran's appeal is open for new evidence, VA.gov displays the following message:



> "Your appeals file is open for new evidence."



The page then lists only a P.O. box and a fax number as submission options.



\*\*VA.gov does not tell veterans that electronic upload is available through QuickSubmit.\*\*



QuickSubmit is the VA's own electronic document submission tool. It already exists. It already works. Veterans are simply never shown the path to it at the moment they need it.



The result: veterans miss deadlines, pay unnecessary postage, receive incorrect mailing addresses, and are denied the ability to defend themselves electronically in their own appeals — in 2026.



## The Fix



This extension detects when a veteran is on their VA.gov appeal status page and the record is open for new evidence. It automatically injects a banner with:



\- A plain-language explanation that electronic submission is available

\- A one-click button to open QuickSubmit

\- A pre-upload checklist so veterans don't miss critical steps



\*\*One click. No mail. No fax. No confusion.\*\*



## How to Install (Chrome and Edge)



1\. Download or clone this repository

2\. Open Chrome or Edge and go to `chrome://extensions`

3\. Turn on \*\*Developer mode\*\* in the top right corner

4\. Click \*\*Load unpacked\*\*

5\. Select the `appeal-evidence-bridge` folder

6\. Navigate to your VA.gov appeal page — the banner will appear automatically



## What This Does Not Do



\- It does not modify VA.gov

\- It does not access or store any veteran data

\- It does not replace QuickSubmit

\- It is not affiliated with the VA



It simply puts a link where it should have always been.



## The Larger Issue



This is a 10-minute fix to a problem that has disadvantaged veterans for years.



The VA's own tool — QuickSubmit — handles the upload. The only missing piece was a link from the appeal status page to that tool. Veterans have been mailing documents to incorrect addresses, paying unnecessary fees, and missing deadlines because that link does not exist on VA.gov.



This extension is proof that the fix is simple. It is being submitted to the VA Office of the CTO and to congressional offices as a documented case for immediate remediation.
